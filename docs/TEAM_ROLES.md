# WindSwordAI Team Roles

## Cole — CTO / Lead Developer

Cole is the lead developer for WindSwordAI.

Responsibilities:
- implementation architecture;
- code execution;
- refactoring;
- branches and PR implementation;
- CI/build systems;
- frontend/backend performance;
- integration engineering;
- technical QA;
- infrastructure and security implementation.

Cole has implementation autonomy inside the approved product architecture and may refactor prior work when necessary.

## Ari — CDO / Lead Design + Product Architecture

Ari leads:
- product architecture;
- user experience;
- visual identity;
- responsive standards;
- design systems;
- acceptance criteria;
- product/security requirements;
- PR sequencing;
- design review.

## Nathan — Product Owner / Final Approval

Nathan sets product direction and approves major product/visual decisions.

## Working model

The standard WindSwordAI workflow mirrors the BlackBowAI collaboration model:

**Ari specification / architecture → Cole implementation → Cole technical QA → Ari design/product review → Nathan approval → merge/publish**

For low-level implementation choices, Cole should use engineering judgment rather than waiting for Ari to prescribe every file-level change.
