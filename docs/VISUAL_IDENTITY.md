# WindSwordAI Visual Identity — PR 02 Draft

This is the first reviewable visual identity, not a locked brand system.

## Direction

- Dark graphite / black gradient environment
- Steel and chrome-inspired structure
- Neon bright blue for focus, selection, secure state, and active controls
- White / cool-gray typography
- Red glow reserved for wake / processing interactions
- Light theme as a first-class alternate presentation
- Compact, modern legal-workspace density rather than a decorative dashboard

## Chat signature

The persistent composer is the center of the product:

`[ + ] Ask WindSwordAI … [voice] [↑]`

The `+` control is the expandable add-on hub for files, photos, matters, connectors, research, and future tools.

The upper chat control exposes reasoning effort with **High** as the initial visual default.
